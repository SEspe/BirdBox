BirdBox — flash a new unit

Flashes the latest built BirdBox firmware onto a blank (or previously different) ESP32-S3 straight from your browser — no ESP-IDF, no esptool install. Works in Chrome or Edge on desktop (Web Serial), over a USB cable.

Your browser doesn't support Web Serial — use Chrome or Edge on desktop. This page needs to be served over HTTPS (GitHub Pages is).
Before you start
  1. Plug the ESP32-S3 board into this computer via USB.
  2. Click Connect device & flash above and pick its serial port from the browser prompt.
  3. If this is a brand-new or previously-different unit, choose Erase device when offered — a clean install avoids leftover NVS/partition state from other firmware.
  4. After flashing, the device reboots into its own BirdBox-Config WiFi access point — see the README's "First startup" section to join it to your network.

Every update after this first flash can go over the air, from the device's own OTA Update tab — this page is only needed once, for the initial flash.

Firmware built automatically from SEspe/BirdBox master via GitHub Actions. See manifest.json for the exact version currently served.
